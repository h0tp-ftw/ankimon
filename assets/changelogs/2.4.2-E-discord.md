## 🌟 Ankimon v2.4.2-E 🌟

A huge thank you to <@1317008280911876109>, <@445586026451173377>, <@720180197403525120> for their contributions to this update! <3

This release includes 4 merged pull requests with 2 enhancements and 1 bug fixes!

Updater hotfix: correctly recognizes dotted versions such as 2.4.1-E and prevents incorrect prompts to downgrade to 2.4-E. Existing affected installations may not discover this release automatically: open Ankimon > Help > Update Ankimon > Releases and select 2.4.2-E, or manually install Ankimon.ankiaddon from this release, then restart Anki. This release also clarifies the Allow Background Checks setting (previously SSH Access).
