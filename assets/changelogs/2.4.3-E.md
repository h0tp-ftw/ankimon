## 🌟 Ankimon v2.4.3-E 🌟

A huge thank you to @Nut2026, @scotej, and @h0tp-ftw for their contributions and help testing this update! <3

This update fixes a startup crash on older Anki versions using Python 3.9, including Anki 24.06 on Windows. It also improves startup and sync reliability and includes the November monthly challenge.

If Ankimon cannot start, download **Ankimon.ankiaddon** from this release, install it through **Tools → Add-ons → Install from file**, and restart Anki. Once Ankimon starts, updates are available through **Ankimon → Help → Update Ankimon → Releases**.

### 🐛 Bug Fixes & Stability!

- Fixed `TypeError: unsupported operand type(s) for |` when loading Ankimon on Python 3.9. #1023
- Prevented automatic startup work and dialogs from blocking Anki sync, and improved startup behavior when switching profiles. #998

### ✨ Features & Improvements!

- Added the November 2026 monthly challenge.
