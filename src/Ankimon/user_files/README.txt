This Folder is needed to place your Ankimon Save Files inside like:
- `backups/` (backups for your Ankimon collection/progress)
- `sprites/` (for Ankimon sprites)
- `sprites_local_manifest.json` that caches sprite metadata
- `update_state.json` which tracks your current Ankimon version/commit
and `ankimon.db` (stores user data, collection, and progress)
